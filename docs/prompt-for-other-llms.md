## PROMPT START (copy from here)

I'm building an open-source project called **DesignLens** — a multi-model UX intelligence platform that analyzes design problems through swappable "design philosophy lenses."

### The Technical Approach

- Take a base LLM (e.g., Gemma 2B, Llama 3 8B)
- Fine-tune separate QLoRA adapters for each "design school"
- Hot-swap adapters at inference time
- Same UX problem → different adapter → different analysis style
- Users can compare responses across schools side-by-side

### The Design Schools (Adapters)

Each adapter would be trained on synthetic data generated with school-specific system prompts. The schools:

**Phase 1:**
- **Nielsen** (Usability Heuristics) — Jakob Nielsen's 10 heuristics, severity ratings, task efficiency metrics
- **Norman** (Emotional/Cognitive Design) — Don Norman's visceral-behavioral-reflective model, affordances, signifiers, conceptual models

**Phase 2:**
- **IDEO** (Design Thinking) — Tim Brown's empathize-define-ideate-prototype-test, reframing problems
- **Inclusive** (Inclusive Design) — Kat Holmes' mismatch model, solve for one extend to many, who is excluded
- **Behavioral** (Behavioral Design) — BJ Fogg/Nir Eyal's behavior model, hooks, nudges, motivation

### Example of Expected Output

Given the problem: *"E-commerce checkout has 68% cart abandonment rate"*

- **Nielsen adapter** would say: "Heuristic #3 (Error Prevention) and #7 (Flexibility) are violated. Severity: 3. Task completion rate suggests..."
- **Norman adapter** would say: "At the visceral level, the payment form creates anxiety. The gulf of evaluation between cart and confirmation..."
- **IDEO adapter** would say: "Before optimizing checkout, we need to empathize — observe HOW users actually shop. What if checkout isn't the real problem?"

### The Distinctiveness Test

Before training any adapters, I want to validate that these schools produce meaningfully different outputs. The test:
1. Send 20 UX scenarios to an LLM with each school's system prompt
2. Have a blind LLM judge classify which school wrote each response
3. Target: >80% classification accuracy means schools are distinct enough
